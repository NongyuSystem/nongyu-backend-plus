### 说明：关于「无直通写入方法」这一预设

背景里举例的「无直通写入方法」**与一手源码不符**：`internal/platform/cache.go:240` 有导出的 `Set(ctx, key, value []byte, ttl)`，`:272` 有导出的 `Delete(ctx, key)`，另有 `Transaction`（`:489`）与 `GetOrLoad`（`:323`）。真正的缺口是 G1 / G3：能力在 `platform` 层已具备，但**没有任何 handler 把回传 JSON 接进来并写进缓存**，教务子域也从未注入 `RedisCache`。本文件据实记录，不沿用该示例。
