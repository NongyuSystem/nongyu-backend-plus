# 川农一次登录覆盖多站点的唯一解

> 状态：**已实测证实**（2026-11-10）。本文件不含任何凭据值。
> 知识库 ES 不可达，本条目暂存仓内，待恢复后补录。

## 结论：两张凭据，各管一半

```
凭据 1  go-admin-tgt（55 字符）  → 管「认证类站点」
凭据 2  ywtb Bearer（47 字符）   → 只管 ywtb 一个站
```

**不需要逐站登录。**

## 凭据 1：go-admin-tgt

### 获取
账密 + 验证码登录 `POST https://auth.sicau.edu.cn/api/v1/cas/login`，
响应 `Set-Cookie` 下发 `go-admin-tgt`（形如 `201690:TGT:xxx`）。

### 用法：对**任意已注册 appid** 换票

```
GET https://auth.sicau.edu.cn/api/v1/cas/login?appid=<站点UUID>
Cookie: go-admin-tgt=<tgt>
→ {"code":200,"msg":"登录成功","data":"<加密>","requestId":"<32hex>"}
→ DecryptYWTB(requestId, data) → {st, tgt, user, callbackUrl, users, uuid}
```

已知 appid（UUID）：

| 站点 | appid |
| --- | --- |
| 教务 jiaowu | `b54a2f27-f7ba-4b91-bbf0-3b2b12244d14` |
| 门户 / WebVPN | `aea49a21-6b26-4e8f-bcfc-80e3de591c93` |

拿到 `st` 后回投各站自己的 caslogin 端点建会话（教务即 `jiaowu.sicau.edu.cn/jiaoshi/aspsso/caslogin.asp?appid=..&ticket=<st>`）。

### 实测证据

| 测试 | 结果 |
| --- | --- |
| 教务 appid `b54a2f27` | `code=200`，解出 `st=ST:Mmk2Fqjr6KrV5uFeX1DM-…` |
| 门户 appid `aea49a21` | `code=200`，解出 `st=ST:lW-zilTbHD8-n-0j-QGYa…` |
| **随机 UUID** | **`code=500 未登录`** ← 说明 appid 必须已注册 |
| `/sso/login?appid=<名>` 带 tgt | 8 个站名全部返回 `cascallback=choose`（已识别登录态） |

### 注意区分：appid 有两种形态

- `/sso/login?appid=ywtb` —— `appid` 是**名字字符串**，用于前端 SSO 路由；
- `/api/v1/cas/login?appid=<UUID>` —— `appid` 必须是**已注册的 UUID**，用于后端换票。

用名字去打 `cas/login` 只有 `ywtb` 碰巧返回 200（因为它恰好被注册成那个名字），其余全部 500。

## 凭据 2：ywtb Bearer

### 为什么需要单独的
**ywtb 完全不认 `go-admin-tgt`**——带 tgt 打它的 API 一律 401。

### 获取
浏览器登录 ywtb 后，token 在 `localStorage` 的 `lifeData` 里：

```
lifeData.data.vuex_token  →  "<用户ID>|<随机串>"（约 47 字符；本文件不记录真实值）
```

前端拦截器逻辑（从其 index.js 提取）：
```js
if (custom.auth) header.Authorization = "Bearer " + vuex_token
```

### 用法

```
POST https://ywtb.sicau.edu.cn/api/m/v1/user/getUserInfo
Authorization: Bearer <token>
Content-Type: application/json
body: {}

→ {"code":200,"requestId":"<hex>","data":"<加密>"}
→ DecryptYWTB(requestId, data) → 完整身份
```

**路径坑**：axios 的 `baseUrl = "/api"`，所以代码里写的 `/m/v1/user/getUserInfo`
完整路径是 `/api/m/v1/user/getUserInfo`。直接打 `/api/m/user/getUserInfo` 会 404。

### 解密后的完整字段

```json
{"number":"<学号>","name":"<姓名>","gender":"男",
 "idcard":"<18位完整号>","phone":"<11位手机号>",
 "unit":"信息工程学院","birthday":"2007-01-14T08:00:00+08:00",
 "groups":["bzks"],"email":"","qq":"","status":1,
 "wechat":"...","expire_at":"2099-12-31T23:59:59+08:00",
 "avatar":"https://jiaowu.sicau.edu.cn/photo_zxs/2025/.jpg"}
```

**这是身份证号的唯一来源**（`idcard` 字段，完整号）。教务 `bjiben.asp` 没有身份证。

| 站点 | 可达 | 技术栈 | 统一认证 |

| jiaowu 教务 | 302 | 传统 ASP（GBK） | CAS，appid `b54a2f27` |
| ywtb 一网通办 | 200 | uni-app SPA + Laravel | **自有 Bearer** |
| xsc 学工 | 200 | 传统 ASP/.NET | 待确认 appid |
| zjc 招就 | 200 | 传统 ASP，含 CAS 字样 | 待确认 appid |

## 操作坑

1. **用外部 curl 打 ywtb 的 `/api` 接口会超时或返回 `000`**——改用浏览器内 `fetch`（同源、自带 cookie）才成功。
2. `POST /api/caslogin`（ywtb 自己的账密登录）连续三次超时，未采用；实际采用「浏览器取 token」。
3. 注入 `go-admin-tgt` 到浏览器 cookie 后，访问 `/sso/login?appid=<名>` 即自动完成 SSO 并生成 ywtb token。
