# 川农一次登录覆盖多站点的唯一解

> 状态：**已实测证实**（2026-11-10）。本文件不含任何凭据值。
> 知识库 ES 不可达，本条目暂存仓内，待恢复后补录。

## 结论：两张凭据，各管一半

```
凭据 1  go-admin-tgt（55 字符）  → 管「认证类站点」
凭据 2  ywtb Bearer（47 字符）   → 只管 ywtb 一个站
```

**不需要逐站登录。**

## 凭据 1：go-admin-tgt

### 获取
账密 + 验证码登录 `POST https://auth.sicau.edu.cn/api/v1/cas/login`，
响应 `Set-Cookie` 下发 `go-admin-tgt`（形如 `201690:TGT:xxx`）。

### 用法：对**任意已注册 appid** 换票

```
GET https://auth.sicau.edu.cn/api/v1/cas/login?appid=<站点UUID>
Cookie: go-admin-tgt=<tgt>
→ {"code":200,"msg":"登录成功","data":"<加密>","requestId":"<32hex>"}
→ DecryptYWTB(requestId, data) → {st, tgt, user, callbackUrl, users, uuid}
```

已知 appid（UUID）：

| 站点 | appid |
| --- | --- |
| 教务 jiaowu | `b54a2f27-f7ba-4b91-bbf0-3b2b12244d14` |
| 门户 / WebVPN | `aea49a21-6b26-4e8f-bcfc-80e3de591c93` |

拿到 `st` 后回投各站自己的 caslogin 端点建会话（教务即 `jiaowu.sicau.edu.cn/jiaoshi/aspsso/caslogin.asp?appid=..&ticket=<st>`）。

### 实测证据

| 测试 | 结果 |
| --- | --- |
| 教务 appid `b54a2f27` | `code=200`，解出 `st=ST:Mmk2Fqjr6KrV5uFeX1DM-…` |
| 门户 appid `aea49a21` | `code=200`，解出 `st=ST:lW-zilTbHD8-n-0j-QGYa…` |
| **随机 UUID** | **`code=500 未登录`** ← 说明 appid 必须已注册 |
| `/sso/login?appid=<名>` 带 tgt | 8 个站名全部返回 `cascallback=choose`（已识别登录态） |

### 注意区分：appid 有两种形态

- `/sso/login?appid=ywtb` —— `appid` 是**名字字符串**，用于前端 SSO 路由；
- `/api/v1/cas/login?appid=<UUID>` —— `appid` 必须是**已注册的 UUID**，用于后端换票。

用名字去打 `cas/login` 只有 `ywtb` 碰巧返回 200（因为它恰好被注册成那个名字），其余全部 500。

## 凭据 2：ywtb Bearer

### 为什么需要单独的
**ywtb 完全不认 `go-admin-tgt`**——带 tgt 打它的 API 一律 401。

### 获取
浏览器登录 ywtb 后，token 在 `localStorage` 的 `lifeData` 里：

```
lifeData.data.vuex_token  →  "<用户ID>|<随机串>"（约 47 字符；本文件不记录真实值）
```

前端拦截器逻辑（从其 index.js 提取）：
```js
if (custom.auth) header.Authorization = "Bearer " + vuex_token
```

### 用法

```
POST https://ywtb.sicau.edu.cn/api/m/v1/user/getUserInfo
Authorization: Bearer <token>
Content-Type: application/json
body: {}

→ {"code":200,"requestId":"<hex>","data":"<加密>"}
→ DecryptYWTB(requestId, data) → 完整身份
```

**路径坑**：axios 的 `baseUrl = "/api"`，所以代码里写的 `/m/v1/user/getUserInfo`
完整路径是 `/api/m/v1/user/getUserInfo`。直接打 `/api/m/user/getUserInfo` 会 404。

### 解密后的完整字段

```json
{"number":"<学号>","name":"<姓名>","gender":"男",
 "idcard":"<18位完整号>","phone":"<11位手机号>",
 "unit":"信息工程学院","birthday":"2007-01-14T08:00:00+08:00",
 "groups":["bzks"],"email":"","qq":"","status":1,
 "wechat":"...","expire_at":"2099-12-31T23:59:59+08:00",
 "avatar":"https://jiaowu.sicau.edu.cn/photo_zxs/2025/.jpg"}
```

**这是身份证号的唯一来源**（`idcard` 字段，完整号）。教务 `bjiben.asp` 没有身份证。

## 各站点技术栈与判定

| 站点 | 可达 | 技术栈 | 统一认证 |
| --- | --- | --- | --- |
| jiaowu 教务 | 302 | 传统 ASP（GBK） | CAS，appid `b54a2f27` |
| ywtb 一网通办 | 200 | uni-app SPA + Laravel | **自有 Bearer** |
| xsc 学工 | 200 | 传统 ASP/.NET | 待确认 appid |
| zjc 招就 | 200 | 传统 ASP，含 CAS 字样 | 待确认 appid |
| cwc 财务 | 200 | — | 待确认 appid |
| lib 图书馆 | 200 | 汇文 LibSicau | 含 CAS 字样，待确认 appid |
| webvpn | 302 | 自研 VPN 壳 | appid `aea49a21` |
| ecology 生态 | **000 不可达** | — | 需经 webvpn 访问 |

## 操作坑

1. **用外部 curl 打 ywtb 的 `/api` 接口会超时或返回 `000`**——改用浏览器内 `fetch`（同源、自带 cookie）才成功。
2. `POST /api/caslogin`（ywtb 自己的账密登录）连续三次超时，未采用；实际采用「浏览器取 token」。
3. 注入 `go-admin-tgt` 到浏览器 cookie 后，访问 `/sso/login?appid=<名>` 即自动完成 SSO 并生成 ywtb token。

# 补记（2026-11-10）：学工系统 xsgz 是唯一数据源

## 维护者决定

`https://xsgz.sicau.edu.cn` 的 detail 端点定为**唯一数据点**；
jiaowu 的 GBK 页面解析与 ywtb 的 getUserInfo 取数**全部 disable**。

理由：这个端点一次返回 **13 个分组**，几乎覆盖用户清单里所有字段，
包括教务与 ywtb 都给不了的身份证号、家庭住址、考生号、紧急联系人、
教育经历、家庭成员、经济情况。

## 端点与请求头（关键：三处极易写错）

```
GET https://xsgz.sicau.edu.cn/gateway/zovecenter-saip-xg-app-student/student/detail/<学号>
```

必须同时带这 5 个头 + 2 个 cookie：

| 名称 | 值 | 写错的后果 |
| --- | --- | --- |
| `h-zove-token` | main-app-access-token | 401 用户身份验证失败 |
| `h-zove-tenantid` | `XG` | 500 系统租户标识不能够为空 |
| `h-zove-source` | **`20000`** | 用主应用的 `20100` → 403 |
| `h-zove-appkey` | **`zovecenter-saip-xg-app-student`** | 用 `...-agg-pc` → 403 |
| `h-zove-userlevel` | **`XS`** | 漏掉 → 403 API 接口资源未授权 |
| `Cookie` | `go-admin-tgt` + `main-app-access-token` + `main-app-level-key` | 401 |

**最容易踩的坑**：主应用 `app.js` 里写的是
`H-Zove-Source: "20100"` / `H-Zove-AppKey: "zovecenter-saip-xg-agg-pc"`，
但**子应用** `subapp/student/static/js/app.*.js` 里是 `20000` /
`zovecenter-saip-xg-app-student`，且**多一个 `H-Zove-UserLevel`**。
照主应用抄会稳定 403「您访问的API接口资源未授权」。

## 三条取数路径的差异（为什么不能套用 jiaowu 的做法）

| 站点 | 取数机制 | 后端能否直接用 tgt 复现 |
| --- | --- | --- |
| jiaowu | `tgt → cas/login?appid=<UUID> → st → 回投建会话 → 抓 GBK 页面` | 能 |
| ywtb | 客户端交 Bearer，`POST /api/m/v1/user/getUserInfo` | 需客户端交 token |
| **xsgz** | 客户端交 `main-app-access-token`，带 5 个 `h-zove-*` 头调网关 | **需客户端交 token** |

xsgz 的 `cas/authCodeLogin?ticket=<st:userId>` 虽然存在，但
用 jiaowu 那种 appid 换出的 st 去调会 401——它要的是浏览器 SSO 重定向
产生、绑定自己 service 的 ticket。因此**沿用 ywtb 的模式：客户端交 token**。

## 落库设计（迁移 0004）

四张表，混合策略，既不丢字段也不怕上游加字段：

- `student_profiles` —— 用户清单里的常用字段建成正规列
- `student_profile_groups` —— 13 个分组的**完整原文**（jsonb），一字不丢
- `student_family_members` / `student_resumes` —— 两个列表分组独立成表

身份证号加密进 `id_card_sealed`（bytea），明文绝不落库；另存后四位便于展示。

## 实测验证链

1. 纯 curl 带齐 header → HTTP 200 / 7288 字节 / `code=0` ✓
2. Go `FetchXSGZStudentDetail` → 取到家庭地址、手机、紧急联系人 ✓
3. 迁移 0001~0004 真实执行 ✓
4. `ParseXSGZDetail` 解析 13 组 → 身份证后4=2614、年龄=19 ✓
5. `SaveXSGZProfile` 落 4 表 → 回读毕业学院/宿舍/家庭地址，子表 13 组/成员2/简历3 ✓

## 踩过的坑（都已修）

- **字段类型**：`personalInfoDto.height` 是 **number**（180），Go 里定义成
  `string` 会让整个响应 Unmarshal 失败。改用 `json.RawMessage` 或 `strField` 兼容。
- **占位符数不匹配**：`student_profiles` 49 列却写了 48 个 `$n` + 2 个 `now()`。
  手写大 INSERT 后必须数一遍：`列数 == 占位符数 + now() 数`。
- **取到数但没人落库**：`SaveXSGZProfile` 写好后长时间没有调用方。
  已用 `TestXSGZSource_TriggersOnDetail` 锁住。
- **迁移新增表会让守卫测试失败**：`platform` 与 `app` 两个包各自硬编码了
  表清单，加表要同步；手写测试 DDL 也要同步加表，否则列形状比对失败。

## 补充：8 个站点的真实性质

维护者最初预期「一次登录后 8 个站都能用」，逐站实测后：

| 站点 | 性质 | 有无个人数据 |
| --- | --- | --- |
| jiaowu 教务 | CAS 换票 | 有 |
| ywtb | 自有 Bearer | 有（身份证唯一来源，现已被 xsgz 覆盖） |
| **xsgz 学工** | SSO 网关 | **有（13 组，最全）** |
| xsc 学工部 | 资讯门户 | 无 |
| zjc 招就处 | 资讯门户 | 无 |
| cwc 财务 | 需额外授权，首页即「没有访问当前栏目的权限」 | 无 |
| lib 图书馆 | 资讯门户；其 opac 子系统是**独立账号体系** | opac 有但不认统一认证 |
| webvpn | VPN 网关 | 不提供数据 |
| ecology | 可达（HTTPS 200） | 未发现统一认证取数入口 |

「认证层全通」不等于「业务数据可取」——这个区分已写进代码 `SiteProfiles` 并用测试锁住。
